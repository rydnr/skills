# Generated concepts start draft and unverified

Concepts the agent writes are marked `generated.by: pythoneda-grill/<model>`, carry `sources` pointing at the originating `.py` and `README.md` on `main`, and start `status: draft` with no `verified` field (unverified trust tier). A human adds a `verified: { by: human:<id>, at: … }` entry to promote them to human-reviewed. We chose this so a machine-authored corpus is distinguishable from human-reviewed content with no tooling.
